# SOP-01: Melayani pertanyaan dan pesanan lewat WhatsApp

Berlaku sejak: Januari 2025
Pemilik prosedur: Dewi (admin WhatsApp)

## Langkah

1. Pelanggan mengirim chat ke nomor WhatsApp toko.
2. Admin membuka spreadsheet Daftar Produk dan mencari produk berdasarkan nama.
3. Jika produk ada dan stoknya lebih dari 0, admin membalas dengan nama produk, harga eceran, dan stok.
4. Jika stoknya 0, admin menawarkan produk lain dari kategori yang sama.
5. Jika pelanggan adalah warung, admin memakai kolom harga grosir.
6. Jika pelanggan memesan, admin mencatatnya di spreadsheet Rekap Order: tanggal, nama pelanggan, nomor WhatsApp, jenis pelanggan, kode produk, dan jumlah. Statusnya diisi "baru".
7. Pak Joko mengecek Rekap Order setiap pukul 10.00 dan 14.00, menyiapkan barang, lalu mengubah status menjadi "siap" atau "batal - stok habis".
8. Setiap sore Pak Joko memperbarui kolom stok di Daftar Produk sesuai hitungan gudang.

## Target layanan

Chat pelanggan dibalas paling lambat 15 menit pada jam kerja, pukul 08.00-17.00.
