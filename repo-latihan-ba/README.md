# Repo latihan BA: Toko Rani

Repo ini berisi bahan permintaan bisnis untuk pelatihan Claude Code bagi Business Analyst. Belum ada kode aplikasi di sini. Kode akan dibuat oleh tim developer berdasarkan BRD, PRD, dan FSD yang disusun BA.

Semua nama orang, angka, dan nomor telepon di repo ini fiktif.

## Struktur

| Folder | Isi |
| --- | --- |
| `docs/permintaan/` | Bahan dari pihak bisnis. Jangan diubah, karena ini sumber yang dirujuk semua dokumen BA |
| `docs/requirements/` | Template BRD, PRD, dan FSD, serta dokumen yang disusun BA |

## Bahan permintaan

| File | Isi | Dipakai untuk |
| --- | --- | --- |
| `email-permintaan-1.md` | Email pemilik toko: pelanggan ingin melihat produk sendiri | Permintaan 1 |
| `notulen-kickoff.md` | Notulen rapat awal dengan pemilik, admin, dan kepala gudang | Permintaan 1 dan 2 |
| `sop-layanan-whatsapp.md` | Prosedur kerja yang berjalan sekarang, masih manual | Permintaan 1 dan 2 |
| `daftar-produk.csv` | Contoh isi spreadsheet Daftar Produk (16 dari sekitar 150 produk) | Permintaan 1 dan 2 |
| `email-permintaan-2.md` | Email pemilik toko: pelanggan ingin memesan langsung | Permintaan 2 |
| `rekap-order-oktober.csv` | Contoh isi spreadsheet Rekap Order bulan Oktober | Permintaan 2 |
